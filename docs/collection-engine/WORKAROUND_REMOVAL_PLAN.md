## Deletion rule

For each row, capture its current function/branch, old and new saved outputs, source/config versions, and the rendered wording in a deidentified replay. Remove the branch only after the generic evidence, service, rate and policy path reproduces supported behavior and refuses unsupported positive collection. Retain legitimate payer-specific transport and rule adapters. A historical positive number is never the expected value by itself.
