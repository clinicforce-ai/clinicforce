OFFICIAL PRODUCT GUIDE

Care workflows,
clearly documented.

ClinicForce connects patient records, clinic intake, and evidence-led insurance estimates. This is the operating map for the people who build and support it.

Read the guide ↓ Open Swagger ↗

01 · START HERE

Three services. One request path.

Local services
PostgreSQL and HAPI FHIR run through Docker Compose.
Backend
FastAPI owns validation, authorization, storage, and integrations.
Frontend
React presents workflows and calls same-origin typed adapters.
docker compose up -d
cd backend && uvicorn app.main:app --reload --port 8000
cd frontend && npm ci && npm run dev

Local Swagger is localhost:8000/api/docs. Use synthetic data only.

02 · ARCHITECTURE

The browser never talks to the database directly.

React browser → CloudFront → FastAPI / ECS → RDS · HAPI · S3

CloudFront serves static frontend files and forwards /api/* and /manifest/* to the Application Load Balancer. The API owns identity, validation, workflow decisions, and third-party calls.

03 · APPLICATION LAYERS

Put each decision where it belongs.

LayerOwnsLocation
FrontendViews, forms, navigationfrontend/src/components
API adaptersCookies, timeout, typed requests, errorsfrontend/src/services/api
BackendIdentity, validation, workflowsbackend/app/api
Stores & integrationsSQL, FHIR, payer/EHR formatsbackend/app/core

04 · INSURANCE

Similar screens, distinct workflows.

Patient upload
Secure expiring link for an insurance card.
Insurance V1 / V2
Staff review of a case and supporting documents.
Commercial estimate
eCW context, eligibility evidence, rate version, and saved calculation.

An estimate is not a payment guarantee. It preserves the evidence, rate version, and assumptions used at calculation time.

05 · INTEGRATIONS

Live payer activity is deliberately gated.

IntegrationRequired state
eCWBackend client, issuer, signing material, and clinic context.
AvailityEnvironment, credentials, practice configuration, staff clinic configuration, and eCW access.
StediSTEDI_EXECUTION_MODE=commercial_pilot and STEDI_LIVE_ELIGIBILITY_ENABLED=true, plus a secret API key.

Confirm route configuration before assuming a payer request occurred. Never blindly retry a paid eligibility request.

06 · OPERATE

Release safely. Investigate without exposing data.

Application pipeline
Tests, immutable ECS images, stack update, S3 publish, CloudFront invalidation.
Infrastructure pipeline
The separate clinicforce-aws repository deploys CloudFormation changes.
CloudWatch
/ecs/clinicforce-production-backend and /ecs/clinicforce-production-hapi.

Access logs carry request metadata, not bodies, cookies, authorization headers, or response bodies. Private-link tokens and sensitive query values are redacted.

07 · REFERENCE

Use the live contract.

The backend publishes OpenAPI JSON and read-only Swagger UI. The frontend’s typed boundary is frontend/src/services/api/.

Protected health information
Use safe request or case identifiers when debugging. Never put patient data, credentials, tokens, or production secrets in logs, examples, screenshots, or tickets.
